# Virat-Kohli-Career-Statistics-Analysis-Dashboard
Virat Kohli Career Statistics Analysis Dashboard

Cricket Performance Analytics

An interactive Power BI dashboard built to analyze Virat Kohli's career batting statistics, providing a consolidated view of performance trends across formats, years, and match milestones. The dashboard combines KPI cards, slicers, and multiple visualization types to surface performance patterns at a glance.

📊 Key Features
1. Career KPI Cards — Displays key career metrics: 430 innings, 21K+ runs, 55.81 average, and 95.95 strike rate
2. Format Breakdown — Segmented view of performance across ODI, Test, and T20I formats
3. Year Range Slicer — Interactive filter (2011–2020) to explore performance trends over any custom period
4. Boundaries Analysis — Donut chart showing the split between 4s and 6s, highlighting scoring style
5. Runs by Year — Bar chart tracking total runs scored per year across the career timeline
6. 50s and 100s by Year — Area chart visualizing the frequency of half-centuries and centuries year-over-year
   
🛠️ Tech Stack
1. Power BI — Dashboard design, DAX measures, and interactive visualizations
2. Power Query — Data cleaning, transformation, and shaping raw statistics into a report-ready format
   
🗂️ Data Source
Virat Kohli career batting statistics dataset, including innings, runs, average, strike rate, format (ODI/Test/T20I), boundaries (4s/6s), and milestone data (50s/100s) by year.

📈 Insights Delivered
1. Identified peak scoring years and performance dips across the career timeline
2. Highlighted format-wise strengths through segmented performance breakdowns
3. Revealed scoring style tendencies through boundary distribution analysis
4. Enabled flexible year-range filtering for period-specific performance comparison
